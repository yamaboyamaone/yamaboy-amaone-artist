# YAMABOY AMAONE — Artist Portfolio

A responsive Vite + React music portfolio for YAMABOY AMAONE with the supplied artist photo, latest release links, selected Audiomack tracks, and social destinations.

## Run locally

Requirements: Node.js 18+ and npm.

```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

The production-ready files are written to `dist/`.

## Deploy to Vercel

Import the repository/project into Vercel. The framework should be detected as Vite. Use build command `npm run build` and output directory `dist`.
